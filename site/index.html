codename

Generate a random code name, suitable as a placeholder for a project name.

Specification syntax

Each of the letters below is substituted by a random word. Any other character is copied verbatim, and acts as a separator.

A
an adverb
a
an adjective
n
a noun
d
a digit [0-9]
g
a greek letter (name)

For example, A-a-n produces code names such as extra-pickled-umbrella.

Names are generated in your browser with a cryptographically secure random number generator; nothing is sent to a server. Source and command line tool.
